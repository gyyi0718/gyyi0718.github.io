2026-10-23 · 식사 목적 분류 강화

배포 전 독립 검토에서 간담회 간식 구매를 식사로 분류한 오류를 발견했습니다. 행을 식사 명시·용도 미확정·간식/음료 명시·혼합 명시로 구분했습니다. 간담회와 정책 회의 기록도 원문 지출 기록으로 유지하며 식사 통계로 단정하지 않습니다. 같은 장소의 기록도 행별로 판단하며 업종·현재 영업은 미확인입니다.

2026-10-23 · 사전선정 없는 서울 탐색

기존 9개 상호 선정 분석과 별도로 보관 원본 124,203행에 주소·반복 문서 기준을 적용했습니다. 목적 수준별 지출 기록을 지역·기관·기간으로 탐색하고 비교할 수 있습니다. 표기 차이가 남아 있으므로 고유 식당 수로 해석하지 않습니다. 전국 지도와의 자료 범위를 별도로 표시했습니다.

2026-10-23 · 전국 좌표 정밀도 정정

지명 분류 3건은 식당 위치로 확인할 근거가 부족해 공개 목록에서 격리했습니다. 상세 주소 없는 9건은 대표 좌표를 제거하고 이름 보관 정보만 유지했습니다. 공개 목록은 2,186항목, 좌표는 2,160항목입니다. 이전 2,189항목 보관본은 로컬과 Git 이력에 보존하며 변경 내역을 제공합니다.

2026-10-23 · 주소별 기록 확장

기존 사전선정 13개 주소의 보관 기록을 2026년 8월까지, 본청·의회·사업소·소방 범주로 확장했습니다. 4,478행의 장소 상세와 비교 기능을 추가했습니다. 기존 본청 2025년 2,699행 분석은 별도로 유지합니다. 수집 범위의 차이를 수요 변화로 해석하지 않습니다.

2026-10-13 · 전국 지도와 지역 탐색 복원

전국 탐색에 필요한 지도까지 함께 제거한 범위를 바로잡았습니다. 17개 시도·229개 지역 자료의 보관 장소 2,189개 항목을 홈과 전국 지도에서 다시 제공합니다. 지역·상호·주소·보관 분류 검색, 장소 목록, 외부 지도 연결, 검색 결과 CSV를 사용할 수 있습니다.

복원 대상은 상호·주소·보관 좌표와 확인 상태입니다. 근거를 다시 연결하지 못한 방문 횟수·집행액·순위는 제공하지 않으며, 옛 지역별 분석 페이지와 통계 합본은 계속 비공개입니다. 아래의 오전 공개 범위 변경 이후 장소 탐색 기능을 복원한 것입니다.

2026-10-13 오전 · 미검증 통계 디렉터리 공개 종료

원문 거래 행을 다시 연결하지 못한 228개 지역 페이지와 합본 후보 JSON·CSV, 옛 지도 내장 자료를 공개 대상에서 제거했습니다. 기존에는 미검증 표시와 검색 색인 제외만 적용했지만, 이용자가 수치를 실제 순위로 오해할 수 있어 공개를 종료했습니다. 해당 옛 주소는 없는 페이지로 응답합니다.

원본은 로컬 백업과 변경 이력에 보존합니다. 사이트에서 내려받을 수 있는 현행 분석 자료로는 제공하지 않습니다. 재공개는 원문·집계 단위·범위가 검증되고 독자에게 유용한 분석이 준비된 경우에만 검토합니다.

2026-10-13 · 서울 분석과 탐색 도구

서울 선정 2,699건을 상호·주소·월·부서·금액으로 직접 탐색할 수 있게 했습니다. 상호 9개와 주소 조합 13개를 구분하고, 전체 서울 식당 순위라는 표현을 쓰지 않습니다. 집행액 평균·중앙값·월별 문서 수의 정의를 명시했습니다.

2026-10-13 · 제주 분류 차이 재분석

2025년에만 ‘미분류’ 48,088행이 나타남을 확인했습니다. 기존 음식 분류+미분류 재관측률 51.0%와, 음식 16분류만의 40.9%를 별도로 제시합니다. 이 차이를 폐업·창업·경기 변화로 해석하지 않습니다.

실제 매출·매출 순위·상위 지표 기반 생존률 해석과 상호 유사도 지도 연결을 종료했습니다. 같은 키의 월 중복을 제거한 관측 비교와 공개 가능한 집계 자료로 대체했습니다.

2026-10-12~13 · 앞선 수치 정정

게시물·월별 묶음·거래 행이 혼재된 값을 고유 식당 수로 표시한 오류, 문서 키 수를 실제 부서 수로 표시한 오류를 철회했습니다. 비식당·장소 오연결·이상금액 의심 105개 항목을 보류했고, 이후 전국 미검증 목록 전체의 공개를 종료했습니다.

서울은 보관 문서 2,157개, 파싱 행 47,231개에서 지정 조건의 2,699개 행을 재집계했습니다. 제주에서는 두 시점 재관측을 연속 영업·폐업으로 해석한 문구를 철회했습니다.
