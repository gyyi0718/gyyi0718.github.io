출처와 재현 자료

공식 홈페이지 링크가 있다고 개별 수치가 검증되는 것은 아닙니다. 서울 표본은 상세문서·행 번호까지 연결했으며 다른 지역은 이전 집계값의 출처 연결이 아직 확보되지 않았습니다. 지역마다 이 상태를 동일하게 표시합니다.

  • 검토 데이터 JSON
  • 지역별 검증 상태 CSV
  • 기존 번호를 보존한 후보 CSV (파일명 호환용 top10이며 전국 순위가 아님)
  • 서울 선정 기록 전체 CSV
  • 서울 수집 상세문서 목록 CSV
  • 보류 항목·이유 JSON
  • 검증 상태 JSON

필드 정의

지표정의·공개 상태
source_document_count서로 다른 공식문서 ID 개수. 서울 표본만 원문 목록과 연결.
parsed_row_count보관 파일에서 읽은 행 개수. 식당 결제 수가 아님.
selected_transaction_count명시한 상호·주소·목적 필터를 통과한 문서·행 개수.
selected_merchant_address_count선정 기록의 상호·주소 키 수. 사업체 수나 고유 식당 수가 아님.
restaurant_transaction_count / unique_restaurant_count동일 모집단의 식당 결제 수 / 고유 식당 수. 검증하지 못해 null.
legacy_record_value / legacy_total_posts이전 파일 값. 의미가 혼재되어 현재 통계에 쓰지 않음.
기존 번호예전 목록의 위치. 보류 후 빈 번호를 유지하며 새로운 순위가 아님.
